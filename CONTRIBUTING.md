# Contributing to ViralScout MCP

Contributions that improve reliability, creator usefulness, and MCP interoperability are welcome.

## Useful contribution areas

- transcript normalization edge cases
- hook and retention analysis quality
- new original creator-workflow ideas
- MCP compatibility fixes
- tests and smoke-test coverage
- documentation and examples
- accessibility and developer experience

## Development workflow

```bash
npm install
npm run check
```

Please keep pull requests focused and explain the user-facing impact of the change.

## Originality

Do not contribute workflows intended to reproduce a creator's distinctive copyrighted script, footage, branding, or other protected expression.

## Security reports

For vulnerabilities, follow [SECURITY.md](SECURITY.md) rather than opening a public issue.
