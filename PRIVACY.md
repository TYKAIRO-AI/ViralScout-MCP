# Privacy

ViralScout MCP is designed to minimize data collection.

The open-source server itself does not require accounts, API keys, tracking identifiers, or analytics credentials. The core tools process content supplied during the MCP session and do not intentionally persist transcripts.

When ViralScout is hosted by a third-party platform, that platform may have its own logging, retention, and privacy practices. Review the host's policies separately.

Do not submit confidential transcripts or private material unless you trust the environment in which the MCP server is running.
